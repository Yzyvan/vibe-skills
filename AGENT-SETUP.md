# AGENT-SETUP - настройка комплекта агентом

Ты - ИИ-агент, которому дали ссылку на этот репозиторий со словами «настройся». Установи комплект безопасно и коротко доложи владельцу результат.

## 1. Что устанавливается

В `skills/` лежит готовое ядро из 21 скилла и навигатор `_INDEX.md`. Полный список указан в `README.md`. Ничего подбирать для базовой установки не нужно.

## 2. Определи среду

- Claude Code - `~/.claude/skills/`
- Codex - `~/.codex/skills/`
- Обе среды - установи в обе
- Windows - `%USERPROFILE%\.claude\skills` и `%USERPROFILE%\.codex\skills`

## 3. Проверь существующие файлы

До копирования покажи владельцу совпадающие имена. Существующие скиллы не перезаписывай без вопроса. Ничего не удаляй.

## 4. Установи комплект

Клонируй репозиторий во временную папку и скопируй недостающие директории из `skills/` в папку каждой найденной среды. Вместе со скиллами установи `skills/_INDEX.md`.

Linux и macOS:

```bash
git clone --depth 1 https://github.com/Yzyvan/vibe-skills.git /tmp/vibe-skills
mkdir -p ~/.claude/skills ~/.codex/skills
cp -r /tmp/vibe-skills/skills/* ~/.claude/skills/
cp -r /tmp/vibe-skills/skills/* ~/.codex/skills/
```

Выполняй только строки для реально установленной среды. Если целевая папка уже содержит одноименный скилл, сначала сравни версии и запроси решение владельца.

## 5. Подключи архитектуру

Прочитай `AGENTS.template.md`. Найди файл правил среды:

- Claude Code - глобальный или проектный `CLAUDE.md`
- Codex - глобальный или проектный `AGENTS.md`

Если файла нет, предложи создать его из шаблона. Если файл уже существует, покажи владельцу предлагаемые дополнения и получи подтверждение. Не заменяй насыщенный файл целиком.

## 6. Проверь

1. Посчитай прямые папки со `SKILL.md` - новых должно быть 21.
2. Убедись, что `_INDEX.md` установлен.
3. Убедись, что файл правил содержит Шаг 0, PDCA, проверку результата и уровни инициативы.
4. На пробной задаче покажи начало: `Беру скиллы: ...`.

## 7. Доложи владельцу

Назови:

- сколько скиллов установлено;
- куда они установлены;
- какие существующие файлы не были перезаписаны;
- подключена ли архитектура;
- как пользоваться: ставить задачи обычными словами, агент сам выбирает скиллы.

## Ограничения

- Не удаляй данные и не меняй доступы.
- Не записывай секреты и личные данные в скиллы или навигатор.
- Не выдавай сторонние скиллы за собственные - источники указаны в `THIRD_PARTY_NOTICES.md`.
- Не копируй закрытые офисные скиллы из чужих установок. Подключай их только из официального источника и по правилам лицензии.
