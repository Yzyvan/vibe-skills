# Навигатор по комплекту

Перед любой задачей выбери подходящие скиллы, назови их пользователю одной строкой и прочитай каждый выбранный `SKILL.md` полностью.

| Скилл | Когда брать | Что дает |
|---|---|---|
| `using-superpowers` | Начало любой новой темы | Обязательный выбор и чтение подходящих скиллов |
| `brainstorming` | Создание или изменение продукта, процесса, функции | Прояснение задачи и согласование дизайна до реализации |
| `verification-before-completion` | Перед заявлением о готовности | Проверка результата фактическими командами и артефактами |
| `agent-harness-construction` | Проектирование инструментов и рабочего контура агента | Четкие действия, наблюдения и восстановление после ошибок |
| `loop-design-check` | Автономные циклы и повторяющиеся агентные процессы | Защита от зацикливания, ложных проверок и неверной цели |
| `safety-guard` | Продакшен, автономная работа, риск удаления | Границы действий и безопасные остановки |
| `grilling` | Пользователь просит допросить или проверить идею | Последовательное интервью по одному решению за раз |
| `handoff` | Передача задачи другому агенту или продолжение позже | Компактный снимок состояния и следующего шага |
| `teach` | Обучение человека навыку или инструменту | Учебный контур с практикой и проверкой понимания |
| `wizard` | Пошаговая ручная настройка для пользователя | Безопасный мастер с проверкой каждого шага |
| `to-questionnaire` | Для работы не хватает данных от другого человека | Короткий проверяемый опросник вместо догадок |
| `data-analyst` | Расчеты, сведение таблиц, выводы по данным | Прослеживаемые цифры и защита от выдуманных результатов |
| `meeting-insights` | Транскрипты встреч и интервью | Разделение фактов, выводов, противоречий и гипотез |
| `strategic-advisor` | Выбор, тупик, противоречие, оценка риска | ТРИЗ, теория ограничений, первопринципы и премортем |
| `content-engine` | Контент для нескольких площадок | Платформенные форматы и система переупаковки материалов |
| `brand-voice` | Нужно писать устойчивым голосом автора или бренда | Профиль голоса на основе реальных образцов |
| `slide-craft` | Любая презентация или отдельный слайд | Композиция, сетка и обязательная визуальная проверка |
| `impeccable` | Создание, аудит или полировка интерфейса | Сильная иерархия, типографика, UX и антишаблонность |
| `ui-ux-pro-max` | Подбор UI-стиля, палитры, шрифтов и UX-паттернов | Локальная база дизайн-решений для web и mobile |
| `emil-design-eng` | Полировка интерфейса и взаимодействий | Детали, которые делают продукт собранным и живым |
| `review-animations` | Проверка анимаций и движения в интерфейсе | Строгий аудит физики, таймингов и доступности движения |
